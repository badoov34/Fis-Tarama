🚀 Kurulum

1. Gereksinimler

  • Docker & Docker Compose
  • Node.js 18+ (Expo için)
  • Google Gemini API Key (opsiyonel)

2. Backend (Docker)

cd fis-tarama
# .env dosyasını oluştur
cp backend/.env.example backend/.env
# JWT_SECRET değiştir!
docker compose up --build -d

3. Mobil Uygulama

cd fis-tarama/mobile
npm install
npx expo start

4. Testler

docker compose exec backend \
  python -m pytest tests/ -v

💾 Veritabanı Yedekleme

Otomatik Yedekleme

  • Her gün saat 02:00'de çalışır
  • Backups klasörüne gzip sıkıştırılmış
  • Tüm kayıtlar süresiz saklanır
  • 24 saatten eski raporlar otomatik temizlenir

Manuel Yedekleme

# Yedek al
docker compose exec backup \
  sh /app/scripts/backup.sh

# Yedekleri listele
ls -lh backups/

# Geri yükle
docker compose exec backup \
  sh /app/scripts/restore.sh \
  fis_tarama_20260828_0200.sql.gz
